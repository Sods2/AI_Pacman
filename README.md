# AI Pac-Man

A university project built as part of an Artificial Intelligence course. The challenge was to develop intelligent agents for the **Ms Pac-Man vs Ghosts Competition** — a well-known AI benchmark where agents must navigate the classic arcade game autonomously.

## About

This project implements AI-controlled agents for Ms Pac-Man using Java, based on the competition framework developed by Philipp Rohlfshagen, David Robles, and Simon Lucas at the University of Essex.

The goal: build a Pac-Man controller that can survive, score points, and outmaneuver ghost agents — all without human input.

## Tech

- **Language:** Java
- **Framework:** Ms Pac-Man vs Ghosts Competition
